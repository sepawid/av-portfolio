What this is

An asset-driven data pipeline that evaluates an autonomous-vehicle perception model: raw detection logs → schema validation → KPI flags (TP/TN/FP/FN, critical failures, localization quality) → Parquet artifacts + a BI report consumed by Redash. Quality is enforced with Dagster asset checks and Pandera; the whole pipeline is covered by unit tests and CI.
